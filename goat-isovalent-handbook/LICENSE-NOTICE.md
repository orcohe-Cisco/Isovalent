# Notice

This handbook is a defensive companion to [Kubernetes GOAT](https://github.com/madhuakula/kubernetes-goat)
(by Madhu Akula, Apache-2.0). GOAT scenario descriptions and commands are
summarized here for defensive mapping. Cilium and Tetragon policy syntax follows
the upstream Cilium (https://docs.cilium.io) and Tetragon (https://tetragon.io)
documentation.

Kubernetes GOAT is intentionally vulnerable — run only in a disposable cluster.
